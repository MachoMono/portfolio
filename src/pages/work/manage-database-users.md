I created this document in version 82 of cPanel & WHM. The [Manage Database Users](https://docs.cpanel.net/whm/sql-services/manage-database-users/) interface helps users administrate their user accounts.

This interface is simple to use, but users can run into problems regarding the character limits on their database users. I created multiple dropdown menus with examples to help users understand the database naming limitations for MySQL and MariaDB.

In version 102, I updated the username limitations section with new information and eventually updated version 82 to match once we added the proper database support.
